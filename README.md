# 🖼️ 图片处理工具 - 整合版

一个功能强大的图片处理工具集，整合了多种常用的图片处理功能，支持批量操作，简单易用。

## 📋 这是什么？

这是一个**Web界面的图片批量处理工具**，提供了6大核心功能：
1. **URL下载图片** - 从CSV批量下载网络图片
2. **图片调整大小** - 批量调整图片尺寸
3. **图片裁剪** - 批量裁剪图片边缘
4. **AI智能扩图** - 使用AI智能扩展图片边缘（需API Key）
5. **3:4比例裁切** - 交互式裁切为3:4比例
6. **图片加字工具** - 批量给图片添加文字（支持动态字段、CSV数据绑定、多颜色随机分配）

**特点：**
- ✅ 支持批量处理，一次处理多张图片
- ✅ 支持CSV文件导入，自动匹配图片和数据
- ✅ 直观的Web界面，无需命令行操作
- ✅ 实时预览效果，所见即所得
- ✅ 支持本地上传和URL下载两种方式

## ✨ 主要功能

### 1. URL下载图片
- 上传CSV文件，批量从URL下载图片
- 可选择CSV中的URL列和命名列
- 支持选择下载

### 2. 图片调整大小
- 支持本地上传和CSV批量上传
- 可选择CSV中的URL列和命名列
- 自定义宽度和高度
- 保持图片质量

### 3. 图片裁剪
- 支持本地上传和CSV批量上传
- 可选择CSV中的URL列和命名列
- 自定义上下左右裁剪像素
- 实时预览效果

### 4. AI智能扩图
- 使用通义千问AI模型智能扩展图片边缘
- 支持批量上传
- 自定义上下左右扩图像素
- **需要配置API Key**

### 5. 3:4比例裁切
- 支持本地上传和CSV批量上传
- 可选择CSV中的URL列和命名列
- 保持高度不变，裁切成3:4比例
- 左右拖动选择裁切区域

### 6. 图片加字工具 ⭐ 新功能
- **动态文字字段**：支持添加多个文字字段（不再限制为2个）
- **CSV数据绑定**：文字内容可从CSV字段动态获取，使用【字段名】格式
- **多颜色随机分配**：每个字段可设置多个颜色，批量应用时随机分配
- **交互式编辑**：鼠标拖动文字位置，实时调整字号、颜色、描边等
- **批量处理**：一次处理多张图片，每张图片自动匹配CSV数据
- **单张编辑**：批量处理后，可单独编辑每张图片的文字
- **智能匹配**：自动匹配图片文件名和CSV中的ID列

## 🚀 快速开始

### 方式一：使用打包好的可执行文件（Windows用户推荐）

1. 从 [GitHub Releases](https://github.com/WANYiran/Image_Processing_Toolkit/releases) 下载 `图片处理工具.exe`
2. 双击运行即可
3. 程序会自动打开浏览器，如果没有自动打开，请手动访问 `http://localhost:5000`

### 方式二：从源码运行（macOS/Linux用户推荐，Windows也可用）

#### 1. 克隆仓库
```bash
git clone https://github.com/WANYiran/Image_Processing_Toolkit.git
cd Image_Processing_Toolkit/integrated_image_tool
```

#### 2. 安装依赖
```bash
# Windows
pip install -r requirements.txt

# macOS/Linux
pip3 install -r requirements.txt
```

#### 3. 配置API Key（可选，仅AI功能需要）
**Windows:**
```bash
set DASHSCOPE_API_KEY=your_api_key_here
```

**macOS/Linux:**
```bash
export DASHSCOPE_API_KEY=your_api_key_here
```

#### 4. 运行程序

**Windows:**
```bash
python app.py
# 或双击 run.bat
```

**macOS/Linux:**
```bash
python3 app.py
# 或运行 run.sh
chmod +x run.sh
./run.sh
```

#### 5. 访问应用
打开浏览器访问：`http://localhost:5000`

## 📖 使用说明

### 通用流程

1. **选择功能**：在主页点击需要的功能卡片
2. **上传文件**：根据提示上传图片或CSV文件（支持拖拽上传）
3. **设置参数**：根据需要调整处理参数
4. **开始处理**：点击处理按钮，等待完成
5. **下载结果**：处理完成后，可以预览、单个下载或批量下载

### 图片加字工具详细使用

#### 第一步：上传文件
1. 上传图片文件（可多选）
2. 上传CSV文件（包含图片数据和文字字段数据）
3. 选择用于匹配图片文件名的CSV列（例如：`album_id`）

#### 第二步：配置文字字段
1. 点击"添加文字字段"按钮添加字段（默认1个，可添加多个）
2. 设置文字模板：
   - 直接输入文字：如 `专辑封面`
   - 使用CSV字段：点击"插入CSV字段"按钮，选择字段，会自动插入【字段名】格式
   - 混合使用：如 `【专辑名】- 第【集数】集`
3. 调整参数：
   - **字号**：拖动滑块调整，支持中心缩放
   - **颜色**：可添加多个颜色，批量应用时随机分配
   - **描边**：设置文字描边粗细和颜色
   - **位置**：鼠标拖动文字到合适位置，或使用滑块调整
4. 实时预览：在左侧预览区域查看效果

#### 第三步：批量应用
1. 点击"确认并应用到所有图片"按钮
2. 等待处理完成（会显示加载提示）
3. 处理完成后会显示成功提示和处理的图片数量

#### 第四步：查看和编辑
1. 在结果区域查看所有处理后的图片
2. 点击图片可单独编辑该图片的文字
3. 支持单个下载或批量下载

#### CSV文件格式示例
```csv
album_id,专辑名,集数,描述
001,我的专辑,1,第一集内容
002,我的专辑,2,第二集内容
```

在文字模板中使用：`【专辑名】- 第【集数】集`，会自动替换为：`我的专辑- 第1集`

## ⚠️ 注意事项

- **文件大小限制**：单个文件最大5GB，批量上传总大小最大5GB
- **支持的格式**：PNG、JPG、JPEG、GIF、BMP、WEBP
- **CSV文件**：必须使用UTF-8编码
- **临时文件**：所有处理文件存储在系统临时目录，程序关闭时自动清理
- **网络要求**：部分功能需要网络连接（如下载图片、AI扩图等）
- **AI功能**：需要配置通义千问API Key才能使用
- **图片加字工具**：
  - CSV文件必须包含用于匹配图片文件名的列
  - 图片文件名需要与CSV中的匹配列值对应（不含扩展名）
  - 文字模板使用【字段名】格式引用CSV字段
  - 第一个颜色不能删除，用于预览显示
  - 批量应用时，每张图片会从配置的颜色中随机选择一个

## 🐛 常见问题

### Q: 程序无法启动？
A: 检查是否安装了所有依赖：`pip install -r requirements.txt`，查看控制台错误信息

### Q: AI功能不可用？
A: 检查是否配置了 `DASHSCOPE_API_KEY` 环境变量，确认API Key是否正确，重启程序使环境变量生效

### Q: 如何更新到新版本？
A: 程序会自动检查更新，如果有新版本，点击"下载更新"链接，下载新版本exe并替换旧版本

### Q: 临时文件在哪里？
A: 存储在系统临时目录，程序关闭时自动清理，不会在本地留下处理痕迹

### Q: 图片加字工具如何匹配图片和CSV数据？
A: 上传CSV后，需要选择用于匹配的列（如album_id），图片文件名（不含扩展名）需要与该列的值对应。例如：图片名为`001.jpg`，CSV中`album_id`列为`001`，即可匹配。

### Q: 图片加字工具支持多少个文字字段？
A: 支持动态添加多个文字字段，不再限制为2个。默认1个字段，可根据需要添加更多。

### Q: 如何让每张图片使用不同的颜色？
A: 在文字字段的颜色设置中，点击"+"按钮添加多个颜色。批量应用时，每张图片会从这些颜色中随机选择一个。
